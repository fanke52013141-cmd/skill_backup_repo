# PRD 三级结构浓缩示例

> 用途：只示范一级、二级、三级结构，以及三类代表页面的详细写法。
> 结构约定：一级标题 = 端 / 业务模块；二级标题 = 页面；三级标题 = 页面区域或规则组。
> 省略边界：本文件仅节选三类页面展示结构，不代表实际 PRD 可以跳过已提供的页面。正式正文需按覆盖清单逐项说明页面、弹窗、字段、状态与角色变体。
> 本文件是结构示例，不是完整 PRD。正式文档仍需按规范补文档信息、背景范围和业务流程图；示例中的业务数值需以真实需求为准。

# 一、APP 端

## 1.1 作答页面

### 1.1.1 页面说明

- **页面来源**：从考试信息展示页点击 `开始答题` 进入。
- **页面定位**：完成题目浏览、作答、标记、自动保存和交卷。
- **页面去向**：点击 `提交试卷` 进入交卷确认；交卷成功后进入考试结束页。
- **再次进入**：未提交时回到本页；已提交时进入考试结束页，不再允许修改作答。

### 1.1.2 顶部与题目区

- **返回按钮**：点击后打开 D01 离开确认。
  - **适用范围**：当前学员处于未提交作答页。
  - **标题、正文与按钮**：[待确认：原型中的 D01 标题、正文、确认与取消按钮原文｜影响：离开提示]。
  - **确认结果**：离开当前页，保留已保存作答；具体返回目标待确认。
  - **取消结果**：留在当前页，保留作答。
  - **其他关闭方式**：[待确认：D01 是否提供关闭入口及其结果｜影响：关闭交互]。
- **试卷标题**：展示当前试卷名称，无特殊交互。
- **答题进度**：展示“已完成小题数 / 总小题数”；选择题选中选项、解答题产生有效作答后计入已完成。
- **题号**：按小题顺序排列，点击后切换到对应题目。
- **题号展示标记**：包含 `当前`、`未作答`、`已作答`、`已标记`；它们是可叠加的视觉标记，不是互斥的服务业务状态。当前题与已标记题的展示不能互相覆盖。
- **题目内容**：展示题号、分值、题干、材料和选项；材料超出内容区域后可滚动查看。

### 1.1.3 作答区

- **作答方式**：根据考试策略展示文本、图片或语音入口。
  - **切换交互**：已有作答内容时，打开 D02 作答方式切换确认。
  - **D02 内容**：[待确认：标题、正文及两个按钮原文｜影响：切换提示]；与 D01 分别记录，不共用其未知文案。
  - **确认结果**：清空原作答并切换方式；取消则不切换，保留原作答。
  - **关闭行为**：[待确认：D02 是否有其他关闭入口及是否保留原作答｜影响：关闭结果]。
- **文本作答**：展示多行输入框并实时统计字数；最多 5000 字，超出后禁止继续输入。
- **图片作答**：单题最多 5 张，单张不超过 7 MB；支持预览、删除和排序。
  - **超限反馈**：图片压缩后仍超过 7 MB 时，提示“上传图片不能超过 7M”，不写入该图片。
- **语音作答**：点击后开始录音，支持删除重录；最长 5 分钟，达到上限自动结束。
- **自动保存**：原文存在“10 秒保存变更内容”和“30 秒全量保存”两种描述。
  - [待确认：两种保存机制是否并存及各自触发范围｜影响：作答数据保存]
- **清空按钮**：点击后打开 D03 清空确认。
  - **D03 内容**：[待确认：标题、正文和确认 / 取消按钮原文｜影响：清空提示]。
  - **确认结果**：清空当前题作答且不可恢复。
  - **取消与其他关闭结果**：[待确认：取消是否保留当前作答、是否提供其他关闭方式及结果｜影响：作答数据]。

  - **确认结果**：提交试卷，成功后进入考试结束页；取消则返回作答页。
  - **关闭行为**：[待确认：是否提供其他关闭方式、关闭后的去向及作答保留规则｜影响：交卷交互]。

# 二、网页端

## 2.1 考试记录列表页

### 2.1.1 页面说明

- **页面来源**：从考试中心首页点击 `考试记录` 进入。
- **页面定位**：供当前用户查询自己的考试记录，并进入作答或结果页面。
- **数据范围**：仅展示当前账号可见的考试记录；无其他角色的数据。
- **页面去向**：点击考试名称或操作按钮，按考试状态进入对应页面。

### 2.1.2 搜索与筛选

- **考试名称搜索**：支持输入考试名称关键字查询；点击 `查询` 后刷新列表。
- **状态筛选**：提供 `全部`、`未开始`、`作答中`、`已完成`；默认 `全部`。
- **时间筛选**：按考试创建时间筛选起止日期；起止日期均填写后才生效。
- **重置**：点击后清空搜索与筛选条件，恢复默认列表和默认排序。

### 2.1.3 列表字段与显示规则

- **考试名称**：展示考试名称；点击后按当前状态进入考试或结果页。
- **考试类型**：展示考试所属类型及子类型，无特殊规则。
- **考试时间**：展示考试开始和结束时间；时间格式为 `YYYY-MM-DD HH:mm`。
- **我的成绩**：已出分时展示分数；未出分展示 `--`，不将未出分按 0 分处理。
- **状态**：展示 `未开始`、`作答中`、`已完成`；状态定义见 `2.1.4 状态与操作`。
- **操作**：按状态展示 `开始作答`、`继续作答`、`查看结果`，具体规则见下一节。

### 2.1.4 状态与操作

- **未开始**：考试尚未到可作答时间；展示 `开始作答`，按钮置灰且点击不产生跳转。
- **作答中**：考试可作答或存在未提交作答；点击 `继续作答` 进入作答页。
- **已完成**：试卷已提交且结果可查看；点击 `查看结果` 进入结果页。
- **结果处理中**：如业务存在该状态，需单独列出展示文案、可点击操作和完成后去向。
  - [待确认：是否存在“结果处理中”状态及其学员可见规则｜影响：列表状态与按钮]

### 2.1.5 分页与数据反馈

- **默认排序**：按考试创建时间倒序排列。
- **分页**：沿用现有网页列表分页组件，无特殊分页交互。
- **无考试记录**：展示空列表提示“暂无考试记录”，不展示操作按钮。
- **查询无结果**：保留筛选条件并提示“未找到匹配的考试记录”，点击 `重置` 可恢复列表。

# 三、管理后台

## 3.1 批改策略列表页

### 3.1.1 页面说明

- **页面来源**：`营销 > 营销打卡 > AI 考试 > 批改策略`；新建或编辑后返回本页。
- **页面定位**：查询、维护并控制批改策略是否可被新业务引用。
- **页面去向**：新建、编辑、复制进入对应策略表单；上下架和删除留在本页并反馈结果。
- **权限**：可查看、可编辑和可上下架的角色需分别确认。
  - [待确认：各操作的执行角色与数据权限｜影响：按钮显示和服务端校验]

### 3.1.2 查询与新建

- **默认排序**：按创建时间倒序排列。
- **搜索框**：支持输入策略 ID 或策略名称查询。
  - [待确认：策略名称采用精确匹配还是模糊匹配｜影响：查询实现]
- **新建按钮**：点击后进入 `新建 / 编辑批改策略页`，表单默认为空。
- **查询反馈**：查询无结果时保留搜索条件并展示空列表；不代表策略被删除。

### 3.1.3 列表字段与显示规则

| 字段名 | 含义或来源 | 展示与特殊规则 |
| --- | --- | --- |
| 批改策略 ID | 系统自动生成的策略标识 | `PG + 月日 + 3 位递增序号`，如 `PG1129001` |
| 批改策略名称 | 策略名称 | 超过 15 字省略，悬停显示完整名称 |
| 考试类型 | 策略所属考试类型及子类型 | 遴选（笔试、面试）、公考（申论、面试） |
| 关联的考试策略 ID | 引用本策略的全部考试策略 ID | 逗号分隔，无关联显示 `--` |
| 创建人 | 创建策略的人员姓 | 无特殊规则 |
| 创建时间 | 策略创建时间 | [待确认：展示格式｜影响：列表字段] |
| 状态 | 策略是否可被新业务引用 | `已上架`、`已下架`；见 3.1.4 |
| 操作 | 对当前策略执行的动作 | 上架、下架、复制、编辑、删除；见 3.1.5 |

### 3.1.4 状态说明

| 状态 | 业务含义 | 进入条件 | 页面表现 | 操作及角色 | 退出与下一状态 | 业务影响 |
| --- | --- | --- | --- | --- | --- | --- |
| 已上架 | 可被新业务调用的策略 | 对已下架策略执行上架；新建时初始状态待确认 | 状态列显示已上架 | 可下架、复制、编辑，不可直接删除；执行角色待确认 | 下架校验通过并确认 → 已下架；占用分支见 3.1.5 | 可被新业务引用；编辑的历史影响待确认 |
| 已下架 | 已停止向新建业务提供选择的策略 | 执行下架成功 | 状态列显示已下架 | 可上架、复制、删除；有历史数据时禁止修改参数；执行角色待确认 | 上架 → 已上架；删除后列表与历史展示待确认 | 既有历史数据不受下架影响；旧任务占用处理待确认 |

### 3.1.5 操作与弹窗

- **下架**：点击后校验是否被进行中或未开始的考试策略引用。
  - 未被占用：打开 D05 下架确认；标题、正文和按钮原文待确认。确认后变更为 `已下架`；取消与其他关闭结果待确认，需明确是否保持原状态。
  - D05 不得直接引用 D06 的删除文案；两者入口及业务影响不同。
  - 已被占用：原文存在“禁止下架”和“软下架”两种规则，不能静默二选一。
    - [待确认：占用时是禁止下架还是软下架；若为软下架，旧任务是否继续使用至结束、新任务是否禁止注册｜影响：状态流转与业务对接]
- **上架**：仅 `已下架` 时显示；点击后直接变更为 `已上架`。
- **复制**：点击后进入新建页并预填原策略数据；策略 ID 留空待生成，名称追加 `-副本`。
- **编辑**：点击后进入编辑页并回填当前策略；已下架且有历史数据时禁止修改参数，提示使用 `复制策略` 创建新版本。
- **删除**：仅 `已下架` 时允许；打开 D06 删除确认，确认后删除，不影响历史数据。
  - **D06 标题、正文与按钮**：[待确认：原型原文及变量｜影响：删除提示]。
  - **取消与关闭**：[待确认：取消是否保留策略，是否提供其他关闭方式及结果｜影响：删除交互]。
  - **已上架时**：提示先下架，不执行删除；该拦截提示原文及呈现形式待确认，不能把它与 D06 合并。

### 3.1.6 业务影响与待确认项

- **新业务影响**：已下架策略不可被新任务选择或注册。
- **历史数据影响**：上下架和删除是否影响历史记录，必须按业务事实写明，不能用“逻辑删除”替代。
- **占用处理**：存在进行中任务时，需明确是禁止下架还是软下架，以及旧任务继续使用的范围。
- **编辑限制**：已下架且存在历史数据时禁止修改参数，通过复制策略创建新版本，避免历史记录口径变化。
- [待确认：删除后列表、历史详情和导出数据中的策略名称如何展示｜影响：历史追溯]

# 四、管理后台服务列表示例（虚构教学材料）

## 4.1 服务列表页

### 4.1.1 页面与字段

- **来源与定位**：从服务管理进入，供教务查看全量记录、教师处理分配给自己的记录。
- **已确认输入**：列为服务编号、学员姓名、手机号、服务状态；仅有 `待领取`、`处理中`、`已关闭` 三种状态。教务可关闭待领取或处理中的服务；教师只能领取分配给自己的待领取服务。关闭服务不删除记录。其他动作不在本例范围。

| 字段名 | 含义或来源 | 显示规则 |
| --- | --- | --- |
| 服务编号 | 服务记录的唯一编号 | 无特殊规则 |
| 学员姓名 | 该服务对应的学员姓名 | 无特殊规则 |
| 手机号 | 该学员登记的手机号 | 无特殊规则 |
| 服务状态 | 服务当前业务阶段 | 三个枚举，见 4.1.2 |

### 4.1.2 服务状态说明

| 状态 | 业务含义 | 进入条件 | 页面表现 | 角色操作 | 退出与下一状态 | 数据与跨页影响 |
| --- | --- | --- | --- | --- | --- | --- |
| 待领取 | 已分配教师，教师尚未接受处理 | 完成分配；前一状态不在本例范围 | 状态列显示待领取 | 对应教师可领取；教务可关闭；教师不可关闭 | 教师确认领取 → 处理中；教务确认关闭 → 已关闭 | 双方各自范围内同一记录同步显示新状态 |
| 处理中 | 教师已领取，服务正在处理 | 教师确认领取 | 状态列显示处理中 | 教务可关闭；教师不可再次领取或关闭 | 教务确认关闭 → 已关闭 | 保留记录，双方状态同步变化 |
| 已关闭 | 服务已终止，不能继续领取或处理 | 教务确认关闭 | 状态列显示已关闭 | 双方仅查看，不显示领取和关闭操作 | 本例终态，无重开入口 | 历史记录保留；不删除记录 |

本例没有提供超时规则，不添加“12小时后撤回”等业务。

### 4.1.3 操作与弹窗

- **领取**：仅对应教师在待领取状态可见，点击打开 S01。
  - **S01 领取确认**：标题“领取服务”；正文“确认领取服务{服务编号}？”；按钮“取消”“确认领取”。
  - **确认**：进入处理中，关闭弹窗并更新记录状态；取消保持待领取。输入明确此弹窗没有关闭图标且遮罩不可关闭。
- **关闭**：仅教务在待领取或处理中可见，按当前状态打开 S02 或 S03。
  - **共用结构**：均无输入项，按钮“取消”“确认关闭”；确认进入已关闭、保留历史记录并关闭弹窗更新状态，取消保留原状态。均无关闭图标且遮罩不可关闭。
  - **S02 待领取关闭**：标题“关闭服务”；正文“该服务尚未领取，确认关闭？”。
  - **S03 处理中关闭**：标题“关闭服务”；正文“该服务正在处理中，关闭后将终止处理，确认关闭？”。
  - S02 与 S03 各自可定位，不能合写成“确认后关闭”而丢掉差异文案。

### 4.1.4 角色差异

| 维度 | 教务（基准） | 教师 |
| --- | --- | --- |
| 数据范围 | 全部服务记录 | 分配给自己的记录 |
| 字段可见性 | 上述四字段 | 与基准一致 |
| 按钮 | 可关闭待领取或处理中记录 | 仅可领取自己的待领取记录 |
| 可编辑范围 | 列表无编辑入口 | 与基准一致 |
| 状态操作 | 待领取 / 处理中 → 已关闭 | 待领取 → 处理中 |
| 弹窗与文案 | S02、S03，正文随状态不同 | S01，标题、正文和确认按钮均不同 |

**覆盖核对（仅为作者示范，不增加正式 PRD 章节）**：1 个页面、4 个字段、3 个状态、3 个弹窗变体、2 种角色均有对应条目；名称和文案来自本例虚构输入。
