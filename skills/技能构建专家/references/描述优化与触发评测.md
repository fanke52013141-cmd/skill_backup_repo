## 1. 触发层（Trigger Layer）的核心职责与底层逻辑

`description` 的职责只有一个：**提高触发准确率（Precision）与召回率（Recall），降低误触发**。

智能体在启动时仅加载所有可用技能的 `name` 与 `description`。只有当用户的请求与 `description` 语义匹配，且该任务超出模型依靠基础工具单步完成的范畴时，智能体才会读取 `SKILL.md` 正文。

编写时需重点防范三类风险：

- **内部黑话与抽象概念**：使用团队内部代号或抽象架构词（如“实现领域实体层级聚合”），导致用户用日常口语提问时完全无法命中。
- **缺乏排除边界**：未声明“不处理什么”，导致在相邻领域的普通任务上频繁乱触发。
- **超长尾部截断**：部分客户端限制初始技能列表最多占用 2% 上下文窗口（或 8,000 字符），超出预算时优先从尾部截断描述。因此**核心动作与高频触发词必须前置**。

## 2. 五要素融合触发公式与四问自检法

编写 `description` 时必须控制在 1024 字符以内，严禁出现 `<` 或 `>` 符号，并采用以下五要素融合公式：

```text
将 [对象/代码/系统] 从 [旧状态或当前状态] 处理到 [目标状态]。
当用户提出 [触发意图 / 常见同义表达] 时触发，即使未显式提及 [专业术语] 也可激活。
适用于 [技术栈 / 文件类型 / 项目类型 / 业务场景]。
包含 [主要动作与核心步骤摘要]。
不处理 [明确排除的非目标范围]。
```

写完 `description` 后，必须用以下**四问自检法**逐条审视；若任一问题无法从描述中直接读出答案，则必须重写：

1. **这是什么任务？**（将什么对象处理到什么目标状态）
2. **用户平时会怎么提？**（包含了哪些口语同义词与隐式表达）
3. **适用于什么场景与技术栈？**（明确了哪些文件扩展名、框架或平台）
4. **不适用于什么场景？**（明确排除了哪些容易混淆的相邻任务）

| :--- | :--- | :--- | :--- |
| **前端路由迁移** | 负责前端项目的路由架构升级与重构。 | 将 Vue 2 (vue-router v3) 项目路由配置与组件守卫迁移至 Vue 3 (vue-router v4) 组合式 API。当用户提出“升级 vue-router”、“迁移路由守卫”、“修复 next() 警告”或“路由升 Vue 3”时触发。适用于 `.vue`、`.ts`、`.js` 路由文件改造。包含语法转换、动态路由添加方式替换与类型补全。不处理 React Router 或后端网关路由配置。 | 明确旧状态到目标状态、补充口语同义词（修 `next()` 警告）、锁定文件后缀并排除 React 与后端路由 |
| **表格数据清洗** | 处理 CSV 文件与数据报表。 | 将原始杂乱的 CSV、TSV 或 Excel 业务表格清洗转换为结构化标准数据集与可视化图表。当用户要求“统计汇总”、“添加衍生列”、“排查缺失值”或“根据表格画趋势图”时触发，即使用户仅提供文件路径而未提及数据分析。适用于 Python pandas 数据处理场景。包含缺失值处理、异常值过滤与图表导出。不适用于数据库跨库 ETL 迁移或纯 Excel 宏公式编写。 | 核心能力前置、覆盖仅给文件路径的隐式提问、与数据库 ETL 和纯公式编辑划清边界 |
| **接口安全审查** | 执行后端代码安全合规扫描与治理。 | 对 Go 与 Python 后端接口代码执行安全漏洞审查并生成带修复 Diff 的审计报告。当用户要求“检查 SQL 注入”、“排查越权漏洞”、“上线前安全 Review”或“审计 API 权限”时触发。适用于 REST 与 GraphQL 接口代码审查。包含参数化查询核验、鉴权中间件检查与敏感字段脱敏核对。不处理前端样式代码审查或基础设施网络防火墙配置。 | 用具体安全漏洞名称替代空泛的“安全治理”，明确产出物为带修复 Diff 的报告 |

## 4. 触发评测查询集（正例 / 近邻反例 / 边界例）设计规范

对于中等及复杂技能，建议在 `evaluation/` 目录下准备约 20 条测试查询，按以下三类构造：

1. **正例（Should-Trigger，8 至 10 条）**：覆盖标准书面指令、口语化同义表达、带拼写瑕疵的提问，以及带有具体文件路径（如 `src/router/index.js`）和业务背景的复杂多步请求。
2. **近邻反例（Near-Misses / Should-Not-Trigger，6 至 8 条）**：切勿使用“今天天气如何”等毫无词汇交集的无效反例。必须设计**共享部分关键词但实际诉求不属于本技能**的近邻干扰项（例如针对“Vue 路由迁移”技能，设计反例为“帮我给现有的 Vue 2 路由加一个页面标题修改逻辑”，虽含 Vue 2 路由词汇，但属于日常功能微调而非版本升级迁移）。
3. **边界用例（Edge Cases，2 至 4 条）**：测试用户未说出核心专业术语、仅描述报错现象或业务痛点时的隐式召回能力。

## 5. 训练集与验证集防过拟合迭代闭环

1. **固定 60% 训练集与 40% 验证集**：将评测查询按正反例比例随机切分为训练集（用于暴露问题并指导修改）与验证集（仅用于检验泛化能力，严禁针对验证集题目改写描述）。
2. **多轮运行统计触发率**：每条查询在独立新会话中运行 3 次，计算触发准确率（Precision）与触发召回率（Recall）。
3. **提炼概念而非硬塞原词**：当正例漏触发时，提炼该查询所属的通用意图类别补充进描述，切勿直接将测试原句词汇照抄进 `description`；当反例误触发时，收紧适用范围定语或补充“不处理……”条款，最后选取验证集得分最高的版本定稿。
